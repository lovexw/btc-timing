# ₿ btc-timing — 比特币最优择时回测

如果每一次都精准买在低点、卖在高点，会怎样？这个单页工具在比特币历史日线数据（2017 至今）中，用动态规划找出「复利收益最高」的买卖组合，并与**全程持有不动**直观对比。

## 特性

- **最优择时回测**：选择起始年份与买卖次数（1–20 次），DP 算法在复利假设下（各段收益率乘积最大）找出理论最优买卖点
- **持有 vs 操作对比**：同样 $10,000 本金，两条资金曲线同图对比、比例条、领先倍数徽章
- **交互图表**：价格走势（对数/线性坐标）与资金曲线两种模式，悬停查看逐日数据
- **联动高亮**：悬停交易明细卡片，图表自动定位对应持仓区间
- **统计指标**：年化收益、最大回撤、实际持仓时间、交易节奏，均附「持有不动」参照
- 零依赖、纯单文件 HTML，Canvas 手绘图表

## 使用

浏览器直接打开 `index.html` 即可，无需构建。

在线版：见 Cloudflare Pages 部署地址。

## 说明

- 数据为内置的比特币历史日价格（2013-04-28 至今，页面使用 2017 之后部分）
- 策略假设：初始资金全部投入、不可分批，卖出后资金全部再投入（复利），空仓期不产生收益
- 结果为历史回测的理论最优解，不代表未来收益，不构成投资建议
